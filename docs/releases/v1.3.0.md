# SkyLog 1.3.0

**发布日期 / Released:** 2026-11-22

## 中文

### 全新首页与深色航电 UI

- 首页重做为深色飞行工作台：左侧为游戏启动，右侧为历史航迹列表，**首页不显示地图**。
- 左侧菜单默认仅显示图标（78px），鼠标移入后向右展开文字导航（252px）。
- 页面切换改为 **150ms 淡入淡出**。
- 地图改为深色 Natural Earth 配色。

### 遥测

- **MSFS 2020/2024**：SimConnect 直接读取；应用启动时自动安装/修复组件，并写入 MSFS `exe.xml`，在模拟器启动时自动唤起 SkyLog。
- **X-Plane 11/12**：优先 UDP RREF；自动安装 FlyWithLua 脚本（若已安装 FlyWithLua），脚本会尝试唤起 SkyLog。
- 地图下方新增全宽长条遥测图：高度（青）、速度（琥珀）、航向（紫）三条轨道实时更新。
- 设置中增加“安装 / 修复组件”和自动安装开关。

### 关闭与托盘

- 关闭窗口时询问“直接退出”或“收进系统托盘”。
- 可勾选“保存我的选择，以后不再询问”；设置中可修改默认行为与询问开关。
- 托盘菜单支持打开 SkyLog 与退出。

### 协议与支持

- 首次启动必须阅读并同意《用户使用协议》与《免责声明》后才能使用；不同意为退出。
- 协议和免责声明可在设置中随时阅读，含生效日期、版本、创作者 Pe1er、DeepSeek 辅助创作说明、软件性质、第三方内容、风险、责任边界与法定责任保留。
- 设置新增“我的赞赏码”，图片下方带“感谢分享 / 感谢开发 / 感谢每一次起飞”的流动文字。
- 删除飞机图库功能及相关图片资源。

### 版本

- 发布 Windows 安装包与 macOS x64 / arm64 应用包。
- 版本号升级至 1.3.0。

## English

### New home and dark cockpit UI

- Home is now a dark flight workspace: simulator launch on the left, historical flights on the right, **no map on Home**.
- The left rail shows only icons at rest (78px) and expands to labelled navigation on hover (252px).
- Page changes use a **150 ms fade**.
- The map uses a dark Natural Earth palette.

### Telemetry

- **MSFS 2020/2024:** SimConnect; components are installed/repaired automatically, and an `exe.xml` entry launches SkyLog when the simulator starts.
- **X-Plane 11/12:** UDP RREF first; the FlyWithLua bridge is installed automatically when FlyWithLua is available and attempts to launch SkyLog.
- A full-width telemetry strip below the map displays altitude (cyan), speed (amber) and heading (violet) as three live tracks.
- Settings include component repair/install and an auto-install toggle.

### Close and tray

- Closing asks whether to **quit** or **keep SkyLog in the system tray**.
- A “save my choice” checkbox suppresses future prompts; Settings lets you change the default and prompt toggle.
- Tray menu can reopen or quit SkyLog.

### Terms and support

- First launch requires accepting the **User Agreement** and **Disclaimer**; declining exits the app.
- Both documents remain readable in Settings and cover effective date/version, creator Pe1er, AI-assisted creation, software scope, third-party content, risk, liability boundaries and non-excludable statutory rights.
- Settings adds the support QR code with a flowing thank-you marquee.
- The aircraft gallery and its image assets were removed.

### Builds

- Windows installer and macOS x64 / arm64 ZIPs.
- Version 1.3.0.
