# SkyLog 1.2.0 · 2026-11-04

> English summary: SkyLog 1.2.0 adds real aircraft photographs with type/registration/age cards, a post-import flown prompt, a real local telemetry bridge for X-Plane 11/12 and MSFS 2020/2024, live map tracking with speed/altitude/heading charts, a Community-aware download centre for FlyByWire / FlightSim.to / 飞行宝, multi-threaded URL downloads with a floating progress button, a first-run appreciation dialog and QQ group, and a richer circular route transition.

## 下载 / Downloads

- Windows: `SkyLog-Setup-1.2.0.exe`
- macOS (unsigned): `SkyLog-1.2.0-mac-x64.zip`, `SkyLog-1.2.0-mac-arm64.zip`

## 新增 / Added

### 真实飞机照片与机型档案

- 首页 6 张飞机照片改为真实航空摄影，并补充机型、示例注册号、机龄、座位、航程、巡航速度和动力字段。
- 照片来自 Unsplash 免费图库，许可与图片 ID 见 [`docs/aviation-photo-credits.md`](../aviation-photo-credits.md)。照片是机型示意图，不是注册号对应实拍。

### 航程状态与飞行数据

- 导入 SimBrief 后询问「这段航程已经飞了吗？」；已飞可直接标记，未飞可进入数据读取流程。
- X-Plane 11/12：FlyWithLua 遥测脚本，读取位置、高度、空速、航向、垂直速度和地面状态。
- MSFS 2020/2024：Community HTML/JS 遥测面板，通过本机 `127.0.0.1:42831` 回传。
- 地图显示实时飞机、状态气泡和蓝色轨迹；右下角显示速度、高度、航向三张图表；结束后保存采样点。
- 自动检测 MSFS Community 与 X-Plane plugins；找不到时提示选择，设置页可修改。

### 下载中心与 URL 下载

- 菜单栏新增「下载」，聚合 FlyByWire 直链、FlightSim.to、飞行宝和 X-Plane 插件资源，支持 MSFS 2020/2024 与 X-Plane 11/12 筛选。
- FlyByWire A32NX / A380X 使用官方 Release 直链；下载后可按 ZIP / 7Z 解压到 Community。
- 受保护资源（FlightSim.to、飞行宝）打开来源页，不绕过登录。
- 4 路 Range 多线程下载，自动识别文件名，显示速度、进度和剩余时间。
- 右下角圆形下载按钮显示进行中的任务与进度；点击进入下载中心。
- 工具箱支持自定义 URL 和目标路径，路径持久化。

### 赞赏与交流

- 首启显示「感谢赞赏」和赞赏码；点击「我已赞赏」显示 QQ 群 `967512206` 与「+QQ群获取更多」。
- 标题栏常驻「我已赞赏」按钮；赞赏完全自愿。

### 视觉

- 圆形扩散转场加入斜向轨迹光带与蒙版淡入淡出，提高不透明度。

## 变更 / Changed

- 版本升级至 1.2.0。
- 下载层改用 Electron `net`，兼容系统代理与证书链。
- README、CHANGELOG、发布说明和图片许可记录同步更新。

## 验证 / Verification

- 50 项单元测试通过。
- Windows 开发版验证了首启赞赏、下载中心、URL 下载、FAB、文件名识别、7Z 解压、社区插件安装、本机遥测桥、实时地图、状态气泡、三张图表与结束保存。
- 未在真实 X-Plane / MSFS 内完整验证插件面板的加载路径；如遇社区包结构差异，请反馈日志。
- macOS 包为未签名、未公证的 `.app` ZIP；首次打开需右键 → 打开，或执行 `xattr -dr com.apple.quarantine /Applications/SkyLog.app`。

## 已知限制 / Known limitations

- FlightSim.to 和飞行宝需要账号登录，SkyLog 只打开来源页面，不提供绕过登录的自动下载。
- X-Plane 遥测需要 FlyWithLua；MSFS 面板需要在游戏内打开。
- 照片是免费图库示意图，不是注册号对应实拍；严格开源授权图片可在后续替换。
- macOS 包在 Windows 上组装，未做原生启动验证。
