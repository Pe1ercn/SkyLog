# SkyLog 1.2.1

**发布日期 / Released:** 2026-11-07

## 中文

这个版本重点修复 **Microsoft Flight Simulator 2024 抓不到飞行数据**，并把首页的飞机照片与机型介绍彻底拆开。

### 修复：MSFS 实时飞行数据

- 1.2.0 的 Community HTML 面板缺少 MSFS 2024 工具栏所需的 `InGamePanels/*.spb` 注册和图标资源，因此面板不会出现在游戏工具栏里，也不会发送数据。
- 1.2.1 改为由 SkyLog 主进程直接使用 **SimConnect** 读取数据，不再需要安装 Community 插件、打开游戏内面板或保持网页打开。
- 覆盖 MSFS 2020 / 2024；自动读取纬度、经度、高度、指示空速、航向、垂直速度和地面状态。
- 启动 SkyLog 且当前选择为 MSFS 时，会自动连接；如果已有未飞航段，第一帧数据会自动开始记录。也可以手动点「读取飞行数据」。
- 断线、模拟器退出与错误状态会显示在 **设置 → 飞行数据连接**。

### X-Plane 11 / 12

- 新增内置 **UDP RREF** 遥测，默认连接 `127.0.0.1:49000`，不再强制依赖 FlyWithLua。
- 如果 X-Plane 没有启用 UDP，仍可安装 FlyWithLua 脚本作为备用方案。
- 设置页会显示 UDP 与 FlyWithLua 的状态，方便区分是端口未开、游戏未运行还是脚本未安装。

### 飞机图库

- 首页「航空小课堂」移除了飞机照片、注册号、机龄和参数卡片，只保留航司主题卡与航空小知识。
- 新增独立「飞机图库」页面，使用 **NASA Image and Video Library** 的公共领域航空摄影。
- 图库只展示画面与视觉标题，**不标注具体机型、注册号或性能参数**；点击可看大图、摄影与 NASA 来源 ID。
- 旧版 Unsplash 机型卡片图片与未使用的机型插画已移除。图片来源说明见 [`docs/aviation-photo-credits.md`](../aviation-photo-credits.md)。

### 其他

- 新增飞行数据诊断面板。
- 版本升级至 1.2.1；Windows NSIS 安装包与 macOS x64 / arm64 ZIP 已重新构建。
- 单元测试 53 项通过。

## English

### Fixed: MSFS live telemetry

The 1.2.0 Community HTML panel never registered in the MSFS 2024 toolbar because it lacked the required `InGamePanels/*.spb` registration and toolbar icon assets. SkyLog 1.2.1 now reads **SimConnect directly** from the Electron main process. No Community package, in-game panel, or browser session is required.

- Supports MSFS 2020 and 2024.
- Reads latitude, longitude, altitude, IAS, heading, vertical speed and on-ground state.
- Starts automatically when SkyLog opens with MSFS selected; the first sample can begin recording a planned flight.
- Connection state is shown under **Settings → Flight data connection**.

### X-Plane 11/12

- Built-in **UDP RREF** telemetry on the default `127.0.0.1:49000`; FlyWithLua is now optional.
- FlyWithLua script remains available as a fallback.
- Diagnostics show UDP and FlyWithLua status separately.

### Aircraft gallery

- The home aviation desk no longer shows aircraft photos, registrations, ages or spec cards.
- A separate **Aircraft gallery** uses public-domain photography from the **NASA Image and Video Library**.
- Photos are visual-only: no aircraft type, registration or performance data is labeled. Click for the full image and NASA credit.
- Old Unsplash card photos and unused aircraft illustrations were removed. See [`docs/aviation-photo-credits.md`](../aviation-photo-credits.md).

### Downloads

- `SkyLog-Setup-1.2.1.exe` — Windows 10/11 x64 NSIS installer.
- `SkyLog-1.2.1-mac-x64.zip` — macOS 12+ Intel.
- `SkyLog-1.2.1-mac-arm64.zip` — macOS 12+ Apple Silicon.
