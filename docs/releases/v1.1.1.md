# SkyLog 1.1.1 — 更新内容 / What's New

发布日期 / Released: 2026-11-01

## 中文

SkyLog 航迹 1.1.1 保留全部飞行日志、SimBrief 导入、地图与游戏会话功能，并针对启动与个性化体验做了大幅更新：

- **首页变成飞行甲板**：左侧选择 X-Plane 11/12 或 Microsoft Flight Simulator 2020/2024 并启动，右侧是机型参数、航空公司图鉴和飞行小知识。原来的概览页移到菜单栏「详情」。
- **更直观的游戏选择**：按系列分成两张主卡，显示已发现数量、来源（Steam / Microsoft Store / 本地）和当前选择；大号启动按钮会显示游戏名与启动来源。
- **首次启动全盘搜索**：第一次启动会自动全盘搜索游戏本体，覆盖非默认安装目录、Steam 库和 macOS Applications；支持随时重新全盘搜索或手动选择。
- **工具箱**：新增「工具箱」菜单，包含 7 个航空公司主题（中国国际航空、中国南方航空、中国东方航空、深圳航空、海南航空、厦门航空、上海航空），主题会改变应用主色、菜单图标和非地图背景。主题使用 16 位兑换码解锁。
- **背景图片**：主题自带背景图，可在设置或工具箱调节不透明度；支持导入自定义背景图（PNG / JPG / WEBP / GIF，最大 8 MB），地图页面保持干净。
- **圆形扩散转场**：在菜单栏切换页面时，以点击位置为中心播放主题色圆形扩散动画。
- **全部航线高亮**：地图新增「全部高亮」功能，所有已存航线使用完整颜色和线宽显示，并自动适配全部航线的视野。
- **macOS 游戏启动修复**：Steam 版 X-Plane 12/11 不再直接打开 `.app`，而是通过 Steam 的 `steam://rungameid/<AppID>` 启动，避免 `libsteam_api.dylib` 缺失导致的 dyld 崩溃。
- **版本升级**：1.1.1；Windows NSIS 与 macOS x64/arm64 构建同步更新。

## English

SkyLog 1.1.1 keeps all flight-log, SimBrief import, map and session features, and brings a major update to launching and personalisation:

- **A flight-deck home page**: choose and launch X-Plane 11/12 or Microsoft Flight Simulator 2020/2024 on the left; aircraft specifications, airline profiles and aviation notes sit on the right. The previous overview now lives under the **Details** menu item.
- **Clearer simulator selection**: two family cards show the number of detected games, the source (Steam / Microsoft Store / local) and the current selection. The large launch button shows the game and launch mode.
- **First-launch full drive scan**: the first launch scans all drives for game installations, including non-default folders, Steam libraries and macOS Applications. A full rescan and manual selection are always available.
- **Toolbox**: a new Toolbox menu with seven airline themes (Air China, China Southern, China Eastern, Shenzhen Airlines, Hainan Airlines, XiamenAir and Shanghai Airlines). Themes change accent colours, menu icons and the non-map backdrop. Each theme unlocks with a 16-character code.
- **Backgrounds**: bundled theme backdrops with adjustable opacity in Settings or Toolbox; custom PNG / JPG / WEBP / GIF import up to 8 MB. The map page stays clear.
- **Circular page transition**: menu navigation expands a theme-coloured circle from the click position before switching pages.
- **Highlight all routes**: a new map control shows every saved route at full colour and width, and fits the map to all routes.
- **macOS launch fix**: Steam-managed X-Plane 12/11 is launched through Steam (`steam://rungameid/<AppID>`) instead of opening the `.app` directly, avoiding the `libsteam_api.dylib` dyld crash.

## 验证 / Verification

- 44 Node.js unit tests pass, covering the new full-disk scanner, Steam app IDs, themes/codes and the existing flight-log flows.
- Windows NSIS installer: install, launch, language switch, toolbox/theme unlock, map highlight and uninstall verified locally.
- macOS bundles: structure, version, icon and symlink integrity checked; native launch was not possible in this Windows environment.
- Actual X-Plane/MSFS launch was not end-to-end tested on this machine because neither simulator is installed here. The macOS Steam path was fixed from the supplied crash report.

## 注意事项 / Notes

- The macOS package is an unsigned, non-notarized `.app` ZIP, not a signed `.dmg`. Right-click → Open on first launch; see the included README for the quarantine command.
- Windows and macOS packages are not code-signed.
- Themes are original interpretations of public airline colours, not official logos. 本应用无任何商业行为，如有侵权请联系删改。
- SimBrief's official plan-creation API requires a Navigraph partner key; SkyLog uses the official dispatch prefill + latest-OFP import flow.
