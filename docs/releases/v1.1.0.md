# SkyLog 1.1.0 — 更新内容 / What's New

发布日期 / Released: 2026-10-31

## 中文

SkyLog 航迹 1.1.0 保留了 1.0 的全部 SimBrief 读取、地图、航段详情、飞行日志、游戏会话和本地数据功能，并新增以下能力：

- **游戏检测与启动**：自动检测 X-Plane 11/12 与 Microsoft Flight Simulator 2020/2024，覆盖 Steam、Microsoft Store、常见安装目录和 macOS Applications；支持手动选择 `.exe` / `.app`，保存默认游戏并从侧边栏或设置页启动。
- **应用内创建 SimBrief**：填写起降机场、机型、航司、航班号、日期时间、航路、备降场和旅客数，打开 SimBrief 官方 dispatch 页面并预填参数；生成 OFP 后回到 SkyLog 导入最新计划。
- **中文 / English 界面**：设置 → 显示偏好 → 界面语言；主要页面、地图国家名、设置、弹窗和动态状态均接入。
- **玻璃磨砂交互**：按钮、地图控制、分段选择器、游戏选项和设置卡片使用半透明模糊、细边框与高光。
- **地图修正**：台湾、香港、澳门作为中国的一部分呈现；增加中国台湾、南海诸岛、西沙群岛、南沙群岛、黄岩岛标注和南海九段线图层；说明页同步标注一个中国原则与南海诸岛、九段线呈现方式。
- **macOS 构建**：新增 x64 / arm64 应用包配置与窗口菜单适配。

## English

SkyLog 1.1.0 keeps all 1.0 SimBrief import, map, flight detail, flight log, session grouping and local-data features, and adds:

- **Game detection and launch**: automatically finds X-Plane 11/12 and Microsoft Flight Simulator 2020/2024 from Steam, Microsoft Store, common install folders and macOS Applications. Manual `.exe` / `.app` selection, saved default game, and launch from the sidebar or Settings.
- **Create a SimBrief plan in-app**: enter origin, destination, aircraft, airline, flight number, date/time, route, alternate and passenger count; open the official SimBrief dispatch page with prefilled parameters, then import the generated OFP back into SkyLog.
- **Chinese / English UI**: Settings → Display preferences → Language. Major pages, map country labels, settings, modals and dynamic states are covered.
- **Frosted-glass interactions**: translucent blur, fine borders and highlights on buttons, map controls, segmented controls, game options and settings cards.
- **Map corrections**: Taiwan, Hong Kong and Macao are shown as part of China. Added labels for Taiwan, China; the South China Sea Islands; the Paracel Islands; the Spratly Islands; and Huangyan Dao, plus a nine-dash-line layer and legend. The About panel states the One-China principle and the map treatment of the South China Sea.
- **macOS builds**: x64 / arm64 app package configuration, native menu and window chrome adjustments.

## Verification / 验证

- 39 Node.js unit tests pass.
- Windows NSIS installer: silent install, launch, English switch, create panel and uninstall verified.
- macOS bundles: structure, version, icon and symlink integrity checked; **not launched on native macOS** in this environment.
- No X-Plane / MSFS installation on the build machine, so real game launch was not end-to-end tested here.

## Notes / 注意事项

- SimBrief's official plan-creation API requires a Navigraph partner access key. SkyLog therefore uses the official dispatch prefill + latest-OFP import workflow; it does not store your SimBrief password or pretend to generate a plan without authorization.
- The macOS package is an unsigned, non-notarized `.app` ZIP (not a signed `.dmg`). On first launch, right-click → Open; if Gatekeeper reports a damaged app, use the `xattr -dr com.apple.quarantine` command in the included README.
- Windows and macOS packages are not code-signed. Windows SmartScreen may show an unknown-publisher warning.
