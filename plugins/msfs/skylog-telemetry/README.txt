# SkyLog Telemetry Bridge for Microsoft Flight Simulator 2020/2024

Copy this folder into your MSFS **Community** folder (SkyLog can do this from
the Download page). Start a flight, open the SkyLog Telemetry panel from the
toolbar, and keep it open while flying. The panel sends data to SkyLog at
`127.0.0.1:42831`.

The panel uses the simulator's HTML/JS SimVar API. It is local-only and sends
no data to the internet.
